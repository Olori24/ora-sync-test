# Opportunity Radar AI (ORA)

This repository contains the foundation for ORA. It is a minimal Next.js + TypeScript scaffold intended for CI validation.

Setup

1. Copy .env.example to .env.local and fill in any required secrets.
2. Install dependencies: npm ci
3. Run locally: npm run dev

CI

- GitHub Actions workflow runs lint, type-check, build, and tests on pull requests and pushes to foundation/initial.

Notes

- This scaffold is intentionally minimal. Do not merge automatically — wait for review.
